# Pixel Clicker (Android)

A lightweight, retro-themed clicker with Mining, Fishing, and Fighting systems.

## Build

- Ensure you have JDK 17 and Android SDK (API 34 recommended)
- Open in Android Studio and click Run, or use Gradle:

```bash
./gradlew assembleDebug
```

If the Gradle wrapper is missing, run with your local Gradle:

```bash
gradle assembleDebug
```

## Gameplay
- Mine, fish, or fight to earn resources and XP
- Stamina regenerates over time
- Leveling up boosts stamina and skills

## Notes
- State auto-saves every second and on background
